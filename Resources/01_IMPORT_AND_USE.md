# Import Into Notion and Use Elsewhere

## Import into Notion

1. Download **Nikyle_Rock_City_Context_Pack.zip** and leave it zipped.
2. Open Notion on a computer or in a desktop web browser.
3. Open **Settings → Import** and choose **Convert Zip to pages**. Alternatively, type **/zip** inside a page and choose that importer.
4. Select the downloaded ZIP and let the import finish.
5. Open **00_START_HERE** within the imported folder. You can rename the containing page **NIKYLE / ROCK CITY HQ**.

The ZIP contains one folder with the Markdown pages and subfolders. Notion documents folder ZIP import as the route for preserving structure. This package has not been imported and tested in your account.

Check that the main page and ministry subpages are present. If a relative navigation link does not convert, find the imported page by title and replace that link with a Notion page mention. The content remains readable independently of those links.

Official guidance: [Notion import help](https://www.notion.com/help/import-data-into-notion), checked 3 October 2026.

## Use as AI context

If the tool accepts ZIP files, upload the pack. Otherwise extract it and upload the Start Here page, working preferences, hard constraints and the topic pages relevant to the task. File support, retrieval and knowledge limits depend on the tool.

Suggested first request:

> Read 00_START_HERE and the pages relevant to my task. Apply the established preferences and constraints. Treat Current Context as a snapshot dated 3 October 2026. Tell me if any required source is inaccessible. My task is: [describe the work].

In Notion AI, explicitly reference the imported Start Here page and relevant ministry/project pages in the request. Do not assume that importing pages alone creates an always-enforced AI instruction system.

## Use with a developer or GitHub

Extract the folder and share it with the developer, or add its contents to a private repository. Start Here serves as the entry point. No repository has been created or published as part of this package.

The Markdown can be edited in any text editor. Relative links are kept within the folder. Ordinary headings, lists and tables make the information portable; the files do not depend on Notion-only features.

## Keep one canonical copy

Choose where the maintained version lives: for example, Notion or a Git repository. Changes in one copy do not automatically update another. Refresh exports or uploads when context changes. Keep dated snapshots so old campaign information is not mistaken for current instructions.

This pack supplies context pages. It does not configure a task database, system integration, permissions, reminders or background automation.
