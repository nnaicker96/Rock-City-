# Notion and Google Drive

## Notion starting point

Nikyle is new to Notion. Begin with pages and files, using clear navigation and practical instructions. Avoid requiring knowledge of formulas, relations, rollups or automations to use the context hub.

This pack provides populated pages rather than an empty structure. A later project/task system can be added after the information is usable.

## Google Drive context

Nikyle wants the Steering Committee to access the relevant Google Drive folders and has specified **My Drive**. Do not assume a Google Workspace Shared Drive or propose controls that depend on a different account setup without checking.

The exact folders, current membership and permissions have not been verified in this pack. A page describing access does not itself grant access.

## Proposed division of work

Use Notion for context, decisions, project notes and navigation. Keep original working files in their chosen file system and link the current source from the relevant page. This is a suggested arrangement; it is not a requirement to move or duplicate every file.

## Portability

The Markdown files are portable text, readable without Notion. A private Git repository can version them. An AI project can receive the ZIP or selected pages if that tool supports those files. A developer can read the same structure directly.

Importing the files into Notion creates a separate working copy. Edits do not automatically flow back to this ZIP, a Git repository or another AI’s knowledge. Choose a canonical copy and refresh other copies intentionally.
