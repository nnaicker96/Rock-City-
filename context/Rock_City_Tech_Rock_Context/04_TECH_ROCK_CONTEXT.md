# Tech Rock — Context and Scope

## Purpose
Tech Rock is Rock City Church’s digital infrastructure, IT and systems function.

## Scope
Tech Rock includes:
- digital infrastructure;
- IT and technical systems;
- Planning Center enablement/administration;
- digital workflow design;
- church apps/web tools;
- repositories and technical documentation;
- data/integration tooling;
- Media.

## Explicit Boundaries
- **Sound is excluded from Tech Rock.**
- **Lighting belongs under Media.**
- Do not use sound desks, microphones, speakers or audio imagery to represent Tech Rock merely because the user also works in sound.
- Tech Rock should not be visually reduced to generic “IT” imagery.

## Operating Principle
Tech Rock should build infrastructure that serves the whole church. A tool may originate as a Tech Rock project but should not be unnecessarily restricted to Tech Rock if the actual requirement is church-wide administration.

## Tech Rock Identity
When designing Tech Rock-specific identity:
- retain Rock City family resemblance;
- use clean Bebas Neue-led typography;
- avoid fake technology marks;
- avoid generic circuit boards, laptops, clouds, gears or code imagery unless specifically relevant;
- avoid invented slogans;
- avoid icons unless they are critical;
- preserve pillar colour meanings;
- no sepia;
- optimise WhatsApp identity graphics for circular cropping when requested.

## Systems Responsibility
Tech Rock should:
- enable;
- document;
- govern;
- test;
- maintain;
- support;
- train;
- improve.

It should not create uncontrolled shadow systems that duplicate Planning Center’s authoritative data.

## Administrative Pattern
Where an executive administrator or systems administrator coordinates rollout, the model is:
**Coordinate → Delegate → Follow up → Test → Confirm completion**

Administration is not the same as personally doing every ministry task.
