# Tech Rock

## Scope

Tech Rock covers digital infrastructure, IT and systems, including Planning Center, Church Center, registrations and related websites. Media is included; lighting falls under Media. Sound is excluded from this scope.

## Operational requirements

The tracker should let members update their work, see responsibilities, track status and deadlines, and view team progress. The requested interface evolved from a structured brutalist direction to a maximalist technology-inspired direction. Use the actual latest project design brief for implementation.

Requested functions include adding and removing tasks, personal boards, priorities, marking completion, workstreams, responsive layout, faster synchronisation and a test-connection function. These are requirements, not proof that the current application implements them successfully.

## Known history

The implementation explored Google Sheets, Apps Script and Netlify. Reported issues included slow synchronisation, task removal failures, missing core.js and deployment/contributor constraints. Any claim that these are fixed requires inspection and verification of the current code and deployed system.

Samona’s onboarding was explicitly removed from a later Tech Rock task scope. Do not re-add it from an older brief. That removal does not itself establish a church-wide change to her role or access.

## Broader direction

The later church admin request expands beyond Tech Rock toward a shared project and task system for the whole church. Keep that broader goal distinct from the existing Tech Rock-specific application.
